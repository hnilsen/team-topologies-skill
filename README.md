# team-topologies-skill

Claude Code plugin with two skills:

- `team-topologies` — reference and review checklist (team types, interaction modes, cognitive load, Conway's law, fracture planes)
- `team-topologies-shapes` — how to draw team maps with the official modeling shapes and colours

## Install

    /plugin marketplace add <path-or-git-url-to-this-repo>
    /plugin install team-topologies@team-topologies-skill
